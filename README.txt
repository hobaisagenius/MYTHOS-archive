MYTHOS — Mythology Archive v1

HOW TO OPEN
1. Download the ZIP.
2. Extract it.
3. Open index.html in Brave, Chrome, Edge, or Safari.

WHAT IS INCLUDED
- Premium dark museum-style design
- Greek / Norse / Egyptian pantheons
- 30+ interactive figure profiles
- Search
- Family trees
- Story archive with chapter readers
- Symbols & artifacts
- Responsive desktop/mobile layout
- No build system required

HOW TO PUT IT ONLINE
This is a static website. Upload index.html, styles.css, and script.js to GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

NOTE
Mythological traditions often have conflicting ancient versions. This first version uses concise mainstream summaries so we can perfect the design and structure first. Later versions can add sources, alternate genealogies, maps, timelines, monsters, heroes, artwork, animations, and much more.
